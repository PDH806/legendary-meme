UEFA 네이션스리그 2026-27 · 리그 A · 5·6차전 11.13 ~ 11.18 (한국 시간)

    토너먼트

    우승 확률 8강 추첨까지 무작위로 1만 번

      대회 한 번 돌려보기

      남은 5·6차전, 8강 추첨, 8강(홈·원정)부터 결승까지 대회를 한 번 치러 봐요. 직접 넣은 점수는 그대로 반영돼요. 대진표에서 팀을 눌러 승자를 직접 정할 수도 있어요.

      조별 순위 확률

      16개국이 4개 조로 나뉘어 홈·원정 6경기를 치러요. 조 1·2위는 8강에 가고, 3위와 4위는 다른 조 3위·4위와 성적을 비교해서 잔류·승강 플레이오프·강등이 갈려요. 확률은 1만 번 중 나온 비율이라, 100%·0%는 남은 경기와 상관없이 확정됐다는 뜻은 아니에요.

      3위·4위 팀 비교

      지금 순위(끝난 경기와 직접 넣은 점수) 기준이에요. 3위 중 상위 2팀은 리그 A에 남고, 하위 2팀은 4위 상위 2팀과 함께 리그 B 2위 팀들과 승강 플레이오프를 치러요. 4위 하위 2팀은 바로 리그 B로 내려가요.

      남은 경기

      점수를 넣으면 그 결과로 고정하고 다시 계산해요. 비워 둔 경기는 전력 점수로 시뮬레이션해요. 오른쪽 숫자는 홈 승 · 무 · 원정 승 확률(%)이에요. 시간은 한국 시간이에요.

      어떻게 계산하나요?

      1. 전력 점수: 1872년부터 2026년 10월 6일까지 국가대표 경기 약 5만 건으로 팀마다 Elo 전력 점수를 계산했어요(스페인 2355, 잉글랜드 2218, 프랑스 2175 …). 홈팀은 전력 점수에 100점을 더해요.
      2. 경기 시뮬레이션: 전력 점수 차이로 두 팀의 예상 득점을 정하고 점수를 무작위로 뽑아요(푸아송 분포). 득점 계산 방식은 2016년 이후 유럽 팀 경기 약 1,700건의 결과에 맞췄어요.
      3. 1만 번 반복: 남은 16경기를 1만 번 치러 보고, 팀마다 순위와 결과(8강·잔류·승강 PO·강등)가 나온 횟수를 세요.
      4. 토너먼트: 8강 대진은 실제로는 리그 단계가 끝난 뒤 추첨해요. 그래서 시뮬레이션마다 조 1위와 다른 조 2위를 무작위로 짝지어요. 8강은 홈·원정 두 경기 합산(2차전은 조 1위 팀 홈)이고, 같으면 연장전과 승부차기를 해요(원정 다득점 없음). 4강 대진도 무작위로 정하고, 4강과 결승은 중립 경기 단판으로 계산해요.
      5. 조 순위 규정: 승점 → 동률 팀끼리 치른 경기의 승점·득실차·다득점(남은 동률 팀끼리 다시 적용) → 전체 득실차 → 다득점 → 원정 다득점 → 다승 → 원정 다승 → 징계 점수 → access list 순위예요.
      6. 3위·4위 비교 규정: 승점 → 득실차 → 다득점 → 원정 다득점 → 다승 → 원정 다승 → 징계 점수 → access list 순위예요. 경고·퇴장으로 매기는 징계 점수는 미리 알 수 없어서 건너뛰었어요.

      확률은 전력 점수만으로 계산한 참고용이에요. 부상, 로테이션, 동기 부여 같은 사정은 반영하지 못해요. 파이널스 개최국의 홈 이점은 개최국이 정해지지 않아 넣지 않았어요.
